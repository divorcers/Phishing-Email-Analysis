# Phishing Email Analysis

## Overview
This project investigates a fictional suspicious email to identify potential phishing indicators and recommend an appropriate response.

## Objectives
- Identify common phishing indicators.
- Assess potential cybersecurity risks.
- Recommend safe incident-response actions.
- Practise writing a structured security report.

## Skills Demonstrated
- Threat identification
- Risk assessment
- Critical thinking
- Security documentation
- Incident-response awareness

## Tools Used
- Visual Studio Code
- Markdown

## Methodology
The email was assessed for urgency, sender identity, link destination and potential credential theft. Findings were documented alongside potential impacts and recommended actions.

## Key Findings
The message uses an urgent deadline, an unverified sender identity and a link that requires further investigation. These indicators suggest a potential phishing attempt.

## Limitations
This was a fictional scenario. No real email headers were analysed, no suspicious links were opened and no accounts or credentials were accessed.

## Conclusion
The exercise demonstrated how to recognise potential phishing indicators, assess risks and recommend safe reporting procedures.
